# 2026-06-27 18:46 — Add chat-interface prompts

User wanted a new `chat/` scope for Claude and ChatGPT chat interfaces, using
their current personal prompts as source material but raising them to the
quality bar of the system prompts. User explicitly requested a plan before
implementation; plan accepted by "Implement."

## Decisions

- Added `chat/claude/instructions.md` and
  `chat/chatgpt/custom-instructions.md` as pasteable chat-interface prompts,
  not local agent system prompts.
- Kept the prompts behaviorally aligned, but did **not** use a byte-identical
  shared core. Claude can carry headings and a little more structure; ChatGPT
  needs compression to fit Custom Instructions.
- Kept the core stance from the user's versions: advisor/mirror, calibrated
  challenge, proportional structure, light labeled inference, verification
  discipline, and simple-over-easy coding guidance.
- Documented `chat/` as a first-class sibling scope in README and AGENTS.md,
  while leaving `scripts/link-system-prompts.sh` scoped to `system/` only.
- Added a ChatGPT character-budget convention rather than a sync/install
  script. Chat UI settings are account/product state, not stable local files
  like `~/.claude/CLAUDE.md` or `~/.codex/AGENTS.md`.

## Review feedback

- Accepted: remove `confidence 1-10`; numeric self-confidence implies false
  precision in a single chat response. Replaced with explicit uncertainty
  flags plus what evidence would resolve the uncertainty.
- Accepted: reduce reliance on tone-only anti-sycophancy. Added structural
  levers: state assumptions first, commit to a position when evidence supports
  one, and do not wait to be challenged.
- Accepted: keep the Claude phrase ban-list despite positive-framing guidance;
  user explicitly values avoiding those stock phrases. Added em-dash bans to
  both prompts.
- Accepted: AGENTS.md's source note contradicted the chat prompt premise.
  Replaced the stale "sycophancy unconfirmed" omission with primary-source
  support from Anthropic and OpenAI, while keeping GPT "over-literal
  compliance" omitted as unconfirmed.
